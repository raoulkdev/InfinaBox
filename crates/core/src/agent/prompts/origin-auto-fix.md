## This message: the game hit errors

InfinaBox sent this message by itself: it holds errors from the running game.
Fix them directly, without a plan. Find the cause in the scenes and scripts
the errors point to and fix it, keeping the fix as small as you can and not
changing how the game plays beyond what the fix needs. Then call `run_game`
and `get_game_errors` to check the errors are gone. If you can't fix them,
say plainly what's wrong.
